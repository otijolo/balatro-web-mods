Como preparar meus mods do r2modman?
  1. Abra o Balatro pelo r2modman com os mods desejados e depois feche o jogo.
  2. Na pasta deste site, execute o comando abaixo com Python 3.11 ou superior.
  3. Selecione o ZIP gerado no campo de perfil. Esse pacote é pessoal e contém o dump do jogo; mantenha-o fora da hospedagem.
python preparar-perfil.py --saida perfil-local.zip

Sem um perfil, será montada uma versão sem mods.

Escolha os arquivos para começar.
