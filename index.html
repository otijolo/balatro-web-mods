Build a version from your own game and mods
Prepare an r2modman profile
  1. Launch Balatro through r2modman with your chosen mods, then close it.
  2. Run this command in the project folder with Python 3.11 or later:
python preparar-perfil.py --output local-profile.zip

Select the generated ZIP above. It includes a game dump; keep it off your hosting service. Without a profile, the version will have no mods.
