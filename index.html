How do I prepare my r2modman mods?
  1. Launch Balatro through r2modman with your chosen mods, then close the game.
  2. In this project folder, run the command below with Python 3.11 or later.
  3. Select the generated ZIP in the profile field. This personal package contains a game dump; keep it off your hosting service.
python preparar-perfil.py --output local-profile.zip

Without a profile, the game will be built without mods.

Select your files to get started.
