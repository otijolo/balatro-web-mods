# Balatro Web with mods

An experimental version based on [W0W53R/web-balatro](https://github.com/W0W53R/web-balatro), for building and running **your own copy** of Balatro in the browser with your local r2modman profile.

The site does not provide the game, mods, or dumps. Builds run in your browser and are stored in IndexedDB. Selected files are never uploaded to the server.

## Usage

1. Launch Balatro through r2modman with your chosen mods, then close the game. This generates the Lovely dump.
2. With Python 3.11+, run this command in the project folder:

   ```powershell
   python preparar-perfil.py --output local-profile.zip
   ```

   To use another profile:

   ```powershell
   python preparar-perfil.py --profile "PATH/TO/PROFILE" --output local-profile.zip
   ```

3. Open the site, select your `Balatro.exe` and profile ZIP, enter a name, and click **Build version**.
4. Click **Play**. Use **Download** to keep a personal backup of the built version.

To serve the site locally: `python -m http.server 8766 --bind 127.0.0.1`. Open `http://127.0.0.1:8766/`.

## Deployment

The files in this repository can be hosted on a static hosting service, including GitHub Pages. The workflow uses an explicit list of public files. Never publish `Balatro.exe`, `.love` files, profile exports, saves, `Mods/`, `dump/`, or the package generated by the download button. Profile exports contain game code in the Lovely dump, even without the EXE.

On GitHub, select **Settings → Pages → Source → GitHub Actions**. Keep the MIT license and upstream credits. Libraries retain their own licenses. Publicly distributing mods requires reviewing their licenses; this repository does not distribute them.

## Compatibility and limitations

The adapter was developed for local files from Balatro **1.0.1o**, Lovely **0.10.0**, Steamodded **26.1002.0**, Amulet **3.6.1**, Cryptid **0.5.17c**, Omegatro **1.0.1**, and Balatro+ **1.0.2-a**. Other versions may need additional changes. The dump must match the mods and game version used to generate it.

- Reconstructs Lovely modules, applies the dump, and adapts file paths to the browser sandbox.
- Adapts known `goto` statements and the OmegaNum FFI representation for Lua 5.1.
- Rewrites numeric comparisons through the syntax tree and preserves OmegaNum NaN rules.
- Adapts shaders for WebGL and mod sounds for audio without native threads.
- Omegatro's free disk space joker is excluded from the pool because the browser cannot access PowerShell. Native HTTP and Steam integrations are unavailable.
- The local Omegatro package references `labubu.ogg`, which is missing from that installation. This sound effect is silent, with a diagnostic warning.
- Saves are separated by version name and site address. Clearing browser data removes local versions and saves. Steam saves are not imported automatically.
- Progress syncs every 10 seconds. Use **Save progress** before closing the tab to confirm the latest data has been written.
- The web random number generator may produce different results from the native version, even with the same seed.
- Changing mods or reloading Lovely patches requires rebuilding the version.

The game has many possible cards, effects, and combinations. A startup test and a round do not guarantee compatibility with all of them.
